# Дневник сделок
Небольшой Python-проект для выгрузки истории сделок у брокера в Excel.

Для аналитики уже выгруженного дневника используйте данный  Julia-скрипт:
```bash
https://github.com/Jeanorochka/julia_tradediary_analysis
```

В моменте работает с ТБАНК Брокером через его АПИ кей, дополню позже работой с БКС, Финам и пр. 
Архитектура сделана так, что других брокеров добавить в целом не сложно без переписывания всей бизнес-логики, форки велкам.

На выходе получается Excel со сделками:

`дата | тикер | цена входа | цена выхода | финрез | комиссия`

Каждый новый запуск создает новый `.xlsx`, старые выгрузки не перезаписываются.

pip install requests openpyxl python-dotenv
