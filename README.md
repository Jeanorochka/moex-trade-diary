## Запуск

```bash
uv sync --locked
```
В корне проекта создайте `.env`,  с токеном вашего брокера.
```dotenv
F.INVEST_TOKEN=токен_финама
T.INVEST_TOKEN=токен_тбанка
```

```bash
uv run python main.py
```

Откроется интерфейс на PySide6 / Qt. Выберите брокера, загрузите счета, укажите период и начальный капитал. Пополнения и выводы можно получить у брокера или ввести вручную. Во время выгрузки отображается её статус, во втором окошке `Аналитика` можно отдельно загрузить выходной эксель, не выходя из программы.

## Аналитика файла

Нажмите «Аналитика файла» в боковом меню. Откроется второе окно, в котором Вы можете выбрать Excel, CSV или TSV по пути и нажать «Рассчитать аналитику».

Показатели, графики, открытые позиции, лучшие и худшие сделки появятся прямо в этом окне. Подключение к брокеру для анализа готового файла не требуется. Для чистого отчёта оставьте рядом его JSON. Если в исходной выгрузке не указан начальный капитал, его можно указать в окне анализа.

## Формат отчёта

Один лист Excel, все сделки, открытые позиции, лучшие и худшие, показатели портфеля и годовая экстраполяция. Внизу таблица и диаграмма результата по активам, с открытым PnL. Для открытых позиций вместо выхода показывается текущая цена.

Доходность считается от начального капитала до полной стоимости портфеля, с учётом пополнений и выводов. Нереализованный PnL уже входит в стоимость. Годовой пересчёт показывает текущий темп, это не прогноз. Если истории для риска мало, показатель отмечен как оценка или ячейка остаётся пустой.

Имя файла по датам, например `20.10.2025_10.10.2026.xlsx`. Все строки остаются на одном листе, при печати он разбит на несколько страниц А4 в книжной ориентации. Рядом полный JSON с данными и исходными отчётами, если он нужен Вам для другого движка.

Без окна:

```bash
uv run python main.py --broker finam --from 25.09.25 --to 18.10.26 --starting-capital 130000
```
