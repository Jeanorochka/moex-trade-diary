# Дневник сделок
Выгрузка истории сделок T-Банка в Excel, аналитика и графики из того же `main.py`.<br>
`v. 2.0.1` - обновлены старые библиотеки (Пандас, httpsx ... ) и заместо них теперь растовые Polars, Primp, orjson<br>
`v. 2.1.1` - добавлен Финам брокер + расширенная портфельная аналитика<br>
`v. 2.2` - переоценка портфеля, денежные потоки, доходность<br>
`v. 3.0` - теперь открывает няшный TKinter интерфейс для выгрузки
Установка :

```bash
uv sync --locked
```
Для выгрузки нужен `INVEST_TOKEN` в окружении или `.env`:
```text
INVEST_TOKEN=your_token
```
Интерактивная выгрузка:
```bash
python main.py
```
Выгрузка с аналитикой и графиками:
```bash
python main.py --from 01.09.26 --to 30.09.26 --analytics
```
Счёт можно указать через `--account-id`. Параметры брокера, часовой пояс, каталог
выгрузок и дополнительные колонки настраиваются в `config.toml`.

Анализ уже выгруженного дневника работает без токена и `config.toml`:
```bash
python main.py --analyze exports/trades.xlsx
python main.py --analyze exports/trades.xlsx --starting-capital 100000 --output-dir analytics
```
Те же параметры доступны через команду `trade-exporter`. При запуске через uv
добавьте `uv run` перед `python` или `trade-exporter`.

Обычная выгрузка сохраняет прежние шесть колонок:
`дата | тикер | цена входа | цена выхода | финрез | комиссия`

`финрез` — gross PnL. Аналитика вычитает модуль комиссии и считает net PnL.
Поддерживаются `.xlsx`, `.csv` и `.tsv` с этими колонками.
В Excel выбирается лист `Сделки`, а если его нет — первый лист.
Даты: `dd.mm.yy`, `dd.mm.yyyy`, ISO или ячейки Excel с датой.

В Excel пять листов:

- `Аналитика`: количество строк FIFO, прибыльных, убыточных и безубыточных, винрейт,
  gross/net PnL, комиссии, средние результаты, профит фактор.
  лучшие и худшие результаты; серии прибылей и убытков; просадки.
- `Сделки`: исходные строки и рассчитанный net PnL.
- `Дни`: дневной и накопленный net P&L, капитал, просадка; два графика.
- `Месяцы`: месячные результаты и столбчатый график net PnL.
- `Тикеры`: результаты по инструментам и график net PnL.

Одна строка FIFO может быть частью закрытой позиции. Статистика считается по
этим строкам, без удаления одинаковых сделок. 
Дневная просадка использует итоги дней, полная — строки FIFO.

Относительная доходность и процентная просадка доступны при положительном
`--starting-capital`. Неопределённые коэффициенты записываются как
пустые ячейки / `null`.

Прежний отдельный [Julia-скрипт](https://github.com/Jeanorochka/julia_tradediary_analysis)
