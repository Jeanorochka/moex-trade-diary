# дневник сделок

v2.5.1 -- теперь выводит чистый отчет

финам и т-банк, акции и фьючерсы. запускаешь main, выбираешь счет и даты, вводишь стартовый капитал. пополнения и выводы можно получить у брокера или вбить вручную.

## как запустить

```bash
uv sync --locked
```

в корне проекта создай `.env`, достаточно токена своего брокера

```dotenv
F.INVEST_TOKEN=токен_финама
T.INVEST_TOKEN=токен_тбанка
```

```bash
uv run python main.py
```

откроется небольшое окно с настройками и статусом выгрузки. если есть оба токена, брокера выбираешь там же.

## что в отчете

один лист excel, все сделки, открытые позиции, лучшие и худшие, показатели портфеля и годовая экстраполяция. внизу таблица и диаграмма результата по активам, с открытым pnl. для открытых позиций вместо выхода показывается текущая цена.

доходность считается от начального капитала до полной стоимости портфеля, с учетом пополнений и выводов. нереализованный pnl уже входит в стоимость. годовой пересчет показывает текущий темп, это не прогноз. если истории для риска мало, показатель отмечен как оценка или ячейка остается пустой.

имя файла по датам, например `20.10.2025_10.10.2026.xlsx`. все строки остаются на одном листе, при печати он разбит на несколько страниц а4 в книжной ориентации. рядом полный json с прежними данными и исходными отчетами.

внутри polars, orjson, primp, fastexcel и xlsxturbo.

без окна тоже можно

```bash
uv run python main.py --broker finam --from 25.09.25 --to 18.10.26 --starting-capital 130000
```

для повторного анализа чистого отчета оставь рядом его json

```bash
uv run python main.py --analyze exports/20.10.2025_10.10.2026.xlsx
```
